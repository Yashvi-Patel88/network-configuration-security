# Network Configuration & Security Optimization

Hands-on lab project configuring and securing an enterprise-style switched and routed network, then systematically troubleshooting it to a fully working state.

## Overview

Configured routers and switches for a multi-segment network with security hardening at Layer 2, then diagnosed and resolved a series of injected faults — achieving a 100% resolution rate across lab simulations.

## Technologies

- **Simulation & analysis:** Cisco Packet Tracer, Wireshark
- **Protocols & services:** DHCP, STP, VLANs, TCP/IP
- **Security:** Port security, DHCP snooping

## What was done

- Configured routers and switches: IP addressing, VLANs, DHCP services, and **Spanning Tree Protocol (STP)**
- Hardened switch access with **port security** and **DHCP snooping** to mitigate rogue DHCP and MAC-flooding risks
- Troubleshot with Wireshark packet captures and Packet Tracer simulations
- Identified and resolved misconfigured VLANs, IP address conflicts, and connectivity faults
- **Result: 100% success rate resolving issues across lab simulations**

## Skills demonstrated

Switch & router configuration · VLANs & STP · DHCP · Port security & DHCP snooping · Subnetting & IP addressing · Packet analysis (Wireshark) · Structured network troubleshooting
